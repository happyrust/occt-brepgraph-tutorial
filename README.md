# OCCT 8.0 BRepGraph：新一代拓扑-几何图模型入门

面向 OCCT 开发者的中文图文教程：BRepGraph 如何解决 TopoDS/BRep 的结构性瓶颈，其实体模型、三级身份体系、Build 管线、RAII 突变与装配原生设计，以及采用策略与性能基准。

纯静态站点，打开 `index.html` 即可浏览。

## 目录结构

- `index.html` — 完整教程页面（可直接部署）
- `tutorial.md` — 教程 Markdown 原稿
- `visuals/` — 各章配图
- `brief.json` — 教程元信息
